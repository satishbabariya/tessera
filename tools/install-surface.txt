# The public installed header surface, one path per line, relative to the
# install prefix's include/ directory. A line prefixed "apple:" installs only on
# Apple platforms.
#
# No line carries that prefix today, and that is the point of recording it here:
# the surface used to differ by platform, because one installed header included
# two headers that only exist under if(APPLE). That header was internal and no
# longer ships, so the macOS and Linux packages now offer the same API. The
# prefix stays supported so the next such divergence is written down in the same
# file as everything else rather than in a second list.
#
# A header appearing here is a promise: it ships, so its contents are public
# API. Adding a line is a deliberate act that needs a CHANGELOG entry.
#
# tools/api-entry-points.txt says which of these a consumer is meant to include,
# and tools/check-surface-is-reachable.sh requires that every line here is
# reachable from one of them.
