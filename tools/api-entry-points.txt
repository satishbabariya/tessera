# The headers a consumer is expected to include, one per line, relative to the
# install prefix's include/ directory.
#
# tools/check-surface-is-reachable.sh compiles each of these on its own against
# the installed package -- which also proves each is self-contained -- and then
# requires that every installed header is either listed here or reached from
# something that is. A header that is neither is a promise nobody could have
# found except by reading the include directory.
#
# That check retired twenty-two headers on its first run: util/base64.hpp,
# util/uri.hpp, util/compression.hpp, util/sha_crypto.hpp, group_writer.hpp and
# eighteen more had installed as public API with no public header mentioning
# them.
#
# Adding a line here is a deliberate widening of the API. Removing one is a
# break. Either needs a CHANGELOG entry.

tessera.hpp
